# KRISTALLPUNK für Foundry VTT

Ein Spielsystem für [Foundry Virtual Tabletop](https://foundryvtt.com/), mit dem sich das Pen-&-Paper-Rollenspiel [KRISTALLPUNK](https://kristallpunk.de) spielen lässt.

> **Status:** in früher Entwicklung. Es gibt noch keine spielbare Version.

## Installation

Das System unterstützt ausschließlich **Foundry VTT v14**.

1. In Foundry unter *Spielsysteme* auf *System installieren* klicken.
2. Unten diese Manifest-URL eintragen und installieren:

   ```
   https://github.com/Lyynix/kristallpunk/releases/latest/download/system.json
   ```

## Versionen

Bis zur ersten vollständigen Version laufen die Versionen als `0.x.y`. Danach folgt die Nummerierung dem Schema `Foundry-Hauptversion.Feature.Fix`, also zum Beispiel `14.2.1`. Unterstützt wird immer nur eine Foundry-Hauptversion.
